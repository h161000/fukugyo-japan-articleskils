## 7. 装飾（`<strong>` と `<b>` の使い分け）

| タグ | 用途 | 使いどころ |
|------|------|-----------|
| `<strong>` | **重要な情報**（SEO的にも重要度を伝える） | 結論、警告、読者が絶対に見逃してはいけない情報 |
| `<b>` | **視覚的な強調**（読みやすくするため） | キーワード、固有名詞、数字、流し読みで目が止まってほしいフレーズ |

**太字は積極的に使う。** 装飾なしの段落が3つ以上続かないようにする。

### 装飾一覧

| 装飾 | 書き方 | 使いどころ |
|------|--------|-----------|
| 赤太字 | `<strong style="color: #e53e3e;">` | 結論・最も伝えたい1文 |
| 大きい赤文字 | `<p style="color: #e53e3e; font-size: 1.25em; font-weight: 700;">` | 冒頭の結論・まとめの最終結論 |
| 黄色マーカー | `<mark>` | 「ここ注意！」のポイント |
| 青文字 | `<span style="color: #001dff;">` | LINE誘導前の呼びかけ |
| 太字（重要） | `<strong>` | 重要情報・警告 |
| 太字（視覚） | `<b>` | 固有名詞・数字・キーワード |

---

### 装飾の適用確認

文章の役割に応じて、次の装飾を使い分ける。

- 赤文字：記事の判断・重要な警告
- 黄色マーカー：読み飛ばしてほしくない条件や注意点
- 青文字：LINE誘導前の、読者への具体的な呼びかけ
- 太字：重要な事実や比較の要点

太字だけで、すべての強調を代用しない。装飾数を稼ぐために、不要な強調や文を追加しない。

確認は次の2段階で行う。

1. MDXに、役割に合った装飾指定があるか
2. 表示画面で、色・文字サイズ・読みやすさが反映されているか

CSSに表示設定があるだけでは、装飾を適用した扱いにしない。マーカーまたは青文字が記事全体で0件の場合は、必要な強調や呼びかけを省いていないか再確認し、採用しない場合は理由をレビューに記録する。件数だけでは合否を決めない。

## 10. トップページ構成

### ファーストビュー（Hero）
- 背景: 紺グラデーション `rgba(30,58,95,.92)` → `rgba(21,45,74,.95)`
- H1: 「その副業、本当に大丈夫ですか？」

- ボタン2つ: 「検証記事を読む →」（白）「マナブに相談する」（緑）
- 統計: 検証済み件数 / 危険判定率 / 調査開始時間

### トラストバー
- 背景: 紺
- 白文字、weight700
- 項目: 「実際に登録して内部を調査」「運営会社・法人登記を確認」「相談は完全無料」

### このサイトについてボックス
- トラストバー直後に配置
- マナブアイコン（80px丸）+ テキスト + プロフィールリンク
- 背景白、border1px solid、角丸8px

### 記事一覧
- 2カラム（メイン + サイドバー320px）
- 記事カード: 縦型、画像上200px + テキスト下
- 判定バッジ + カテゴリ + 日付

## 12. LINEバナーの作り方

HTML/CSS → Playwright → WebP で作成。

**テンプレート:** `/tmp/line-banner.html`

**手順:**
1. HTMLでバナーデザインを作る（600x297px）
2. Playwrightで `device_scale_factor=2` でスクショ → PNG
3. `cwebp -q 90` でWebP変換 → `public/images/line-banner.webp`

**デザイン仕様:**
- サイズ: 600x297px
- 背景: LINE緑グラデーション `#06C755` → `#05a046`
- 左: マナブアイコン（100px丸、白ボーダー）
- テキスト: 白+黒縁（text-shadow）、ハッシュタグは黄色（`#ffe066`）
- CTAボタン: 白背景、緑文字、角丸30px

## 13. SEOページ（固定ページ）

4ページ全てに共通：
- パンくず（HTML + JSON-LD BreadcrumbList）
- WebPage JSON-LD
- 最終更新日
- 関連ページリンク
- 同じCSS（`.static-page` / `.static-main`）

| ページ | パス | JSON-LD |
|--------|------|---------|
| 運営者情報 | `/about/` | AboutPage + Organization |
| プライバシーポリシー | `/privacy/` | WebPage |
| 免責事項 | `/disclaimer/` | WebPage |
| コンテンツ制作ポリシー | `/content-policy/` | WebPage |

コンテンツ制作ポリシーの調査手法セクションはフロー形式（番号付きカード + 矢印）。

## 18. やってはいけないこと

- `<br>` を使う
- Google Fontsを読み込む（システムフォントのみ）
- 記事以外での絵文字使用（AIっぽくなる）
- テーブル内のメールアドレス・URLをリンクにする
- 吹き出しを2つ連続で並べる
- LINEボタンの文面をコピペする
- 装飾なしの段落が3つ以上続く
- 角丸を8px以外にする（統一）
- `#2563eb` を使う → 青文字は `#001dff`
- 「稼げる副業を教えます」系の訴求をする
- noindexを解除する（本番は別ドメイン）
