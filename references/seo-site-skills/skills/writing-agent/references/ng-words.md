# 言葉づかいルール

副レポの記事で使う言葉のルール。
「法的にヤバいもの」と「読者に通じないもの」だけ禁止。それ以外はストレートに書く。

---

## 使ってOK（以前はNGだったが解禁）

| 表現 | 使い方 |
|------|--------|
| 詐欺 | タイトル・見出し・結論で自由に使用OK |
| 危険 | 「登録は危険です」等の文脈でOK |
| 怪しい | 自由に使用OK |
| 詐欺まがい | まとめの見出し・結論で使用OK |
| 被害 | 文脈に応じて使用OK |
| 騙された | 口コミ引用や読者の声として使用OK |

---

## レベル1: 絶対禁止（法的リスクあり）

記事本文・見出し・メタディスクリプションのどこにも使わない。

| NGワード | 理由 |
|---------|------|
| 犯罪 | 断定は法的リスクが高い |
| 違法 | 法的判断は裁判所がするもの |
| 逮捕 | 事実でない限り名誉毀損 |
| 返金させる方法 | 法律行為の指導に該当する可能性 |
| 訴える | 法的助言に該当する可能性 |
| 犯人 | 名誉毀損のリスク |

## レベル1.5: ブーメラン禁止（自分にも当てはまる批判）

| NGワード・表現 | 理由 |
|--------------|------|
| LINEアカウントが「未認証」 | 自分のLINEも未認証。ブーメランになる |
| LINE公式アカウントの認証有無への言及 | 同上 |
| 「電話もサポート費用もいらないやり方」等、電話サポートを不要と謳う訴求 | **自分のLINEでも電話サポートを提供している。ブーメランになる**（2026-08-06 管理人さん指摘・nhk-no/shu-sumaho-fukugyo） |
| 電話で話すこと自体・電話番号を取ること自体を悪として書く | 同上。叩くのは「電話で何を言われるか」「渡した番号がどう使われるか」の具体だけ |

**原則:** 検証対象を批判するとき、自分（筆者・サイト）にも当てはまる内容は使わない。

**クロージングで特に事故りやすい。** 「〇〇がいらないやり方なら知っています」の型は、〇〇に自分もやっていることを入れてしまいがち。**入れてよいのは「私が実際に手を動かして続けられたやり方」のように、自分の実践を主語にした言い方だけ。**

---

## レベル2: 肯定的表現の禁止（アンチマーケ）

検証対象を肯定する表現は使わない。

| NGワード | 理由 | 言い換え |
|---------|------|---------|
| 稼げる（肯定的に） | 検証対象を推奨してしまう | 「稼げるとは確認できない」 |
| おすすめ（肯定的に） | 推奨に該当する | 「おすすめできません」はOK |
| 信頼できる | 検証対象への肯定 | 「信頼できるか判断が難しい」 |
| 実績がある | 確認していない限り使わない | 「実績は確認できませんでした」 |

## レベル2.5: ブーメラン禁止（その2）

| NGワード・表現 | 理由 |
|--------------|------|
| 「複数のドメインで同じ広告を展開」等のドメイン数への言及 | 自分も複数ドメインで運用している。ブーメランになる |
| ドメインが怪しい・不審なドメイン | 同上。ドメイン自体を叩かない |

**例外:** 公的機関や大手メディアを模した偽サイト（例：読売新聞を模しているのにドメインが違う）は指摘してOK。これはドメイン数の問題ではなく「なりすまし」の問題なので別。

---

## レベル2.7: ブーメラン禁止（その3）ビジネスモデル批判

| NGワード・表現 | 理由 |
|--------------|------|
| 「無料で始めさせて高額商品を売りつける」 | 自分たちもLINE無料相談→有料商品の紹介をしている。ビジネスモデル自体への批判はブーメラン |
| 「売りつけてくる」 | 有料商品を販売すること自体は合法。「売りつける」は販売行為そのものへの否定 |
| 「心理的に誘導」 | マーケティングはすべて心理的誘導。自分たちもやっている |
| 「期待感を煽る」 | 広告で期待を持たせること自体は普通のこと。自分たちもやっている |
| 「高額商品を売るための手口」 | 有料商品を販売する導線をそれ自体「手口」と呼ぶのはブーメラン |
| 「メールからLINEへの誘導は典型的な詐欺」 | 自分たちもメール→LINE誘導をしている。LINE誘導自体を批判しない |
| 「LINEに誘導するのは〇〇の常套手段」 | 同上。LINEへの誘導は自分たちのビジネスの核 |

**原則:** 「無料→有料」のビジネスモデル自体を悪として批判しない。自分たちもやっていることだから。

**批判すべきポイント:** 商品の中身がない、成果が出ていない、連絡が取れなくなる、返金されない、経歴が虚偽、特商法がない、等の**具体的な不正や不誠実さ**を指摘する。

## レベル3: 難しい言葉の禁止（読者への配慮）

読者はネットリテラシーが高くない人が多い。以下は使わない。

| NG表現 | 言い換え |
|--------|---------|
| 有耶無耶 | 「はっきりしない」「あいまい」 |
| 玉石混交 | 「良いものと悪いものが混ざっている」 |
| 一概には言えない | 結論をはっきり書く |
| 賛否両論 | 具体的にどんな声があるか書く |
| エビデンス | 「根拠」「証拠」 |
| スキーム | 「仕組み」 |
| ローンチ | 「公開」「発売」 |
| マネタイズ | 「お金を稼ぐ仕組み」 |
| リテラシー | 「知識」「理解力」 |
| コンバージョン | 説明なしでは使わない |
| LP | 「広告」「広告サイト」「サイト」に言い換える。読者にLPは通じない |
| アフィリエイト | 初出時は「紹介報酬の仕組み」と説明を付ける |
| 特定商取引法 | 「特定商取引法（ネット販売のルール）」とカッコ書きで説明 |
| 案件 | 「副業情報」「ネットビジネス」「副業」等に言い換える |
| 入り口・入口 | 「広告」で伝わる。「広告の入り口は〜」ではなく「広告は〜」。禁止語（何度も指摘されている） |
