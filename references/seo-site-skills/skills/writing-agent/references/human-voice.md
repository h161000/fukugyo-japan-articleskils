# 人間味の教材（before → after で寄せる）

このファイルは「人間味・人間臭さ」を**実物の見本**で掴むための教材。ルールで縛るとまたAIっぽくなるので、before→after を読んで“正解の温度”に寄せる。抽象ルールは SKILL.md の「人間味のある文体」「装飾のメリハリ」を併読。

**このファイルは全キャラ共通の普遍教材**（キャラごとに別々に持たない・全AIサイトで併用する）。キャラを置かないサイト（編集部名義の検証メディア等）は、以下の「キャラ」を**「筆者＝編集部／当サイト」と読み替える**。原則も例文の技法もそのまま効く（before→after の“ヤマト”を、各サイトのキャラ名／編集部に差し替えるだけ）。

教材アンカー（人間が書いた/手直しした本物）:
- 千葉さんの記事 `recruitgroup.jp/hayashi`（共感先行の冒頭・一人称の主観・実体験クロージング）
- 以下の ponyo / cols の before→after（実際に管理人さんと詰めたもの）

## 大原則：記事の目的は「キャラを好きにさせてLINE登録」

検証を正しく届けることがゴールではない。**読者にこのキャラ（ヤマト等）を「この人に相談したい」と思わせて、LINE登録させること**がゴール。記事もSEOも、そのための手段。（キャラを置かないサイトは「**筆者＝編集部／当サイトを信頼させて相談・LINE登録へ**」と読み替える。仕組みは同じ。）

だから:
- **審判者ヅラの口調を使わない。** 「ここが一番注意してほしいところです」のような“上から評定する”語りは、読者と距離を作りキャラ売りに逆効果。
- 全セクションを「このキャラの人柄・正直さ・親身さ」を積む場として書く。検証内容は**キャラを好きにさせる素材**。
- 人間味リライト（共感・一人称の主観・余韻）は目的でなく手段＝**登録（CVR）を増やすため**にやっている。

## 人間味＝「短く・具体・素の反応」（丁寧に長く整えるのは逆効果）

**最大の誤解を先に潰す。「AIっぽい」の逆は“やわらかく丁寧に整える”ではない。**
人間っぽい記事はむしろ **短く・具体的で・スキャンでき・素のリアクションが挟まる**。丁寧に長くするほどAI臭くなり、CVも落ちる。
教材アンカー：宮崎（fukugyo-check の検証記事＋まとめ記事＝カジュアルな合いの手）／yakkei藤原（`210oku-shien-project` 等＝ぶっきらぼうなほど直球で短い）。どちらもCVが出ている“人間ベンチ”。

### 言い回し

1. **事実→短い“生リアクション”を地の文で。** 吹き出し・青字に整形しすぎない。宮崎「意味のない説明がダラダラ送られてくるだけです」「道のりが遠すぎます」／yakkei「もう答えは出ていますよね」「352万円…一瞬で奪われています」（“…”で余韻、句点なしも可）。
2. **出し惜しみ繋ぎ禁止（最重要・再掲）。** 「問題は、その先です」「さらに、いちばん重い点が」でタメない。**その場で中身を名指す。**
3. **スキャンできる形にする。** 危険ポイントは AlertBox で箇条書き、手口は「ステップ1〜」の番号で。全部を散文で説明しない。
4. **具体で刺す。** 「高額」→「352万3,000円の被害」、「怪しい会社」→「案内人はフリー素材・使い捨てドメイン・別名の同一グループ」。数字と固有名詞で。
5. **盛らない・飾らない。** 赤太字/マーカーは要点だけ。丁寧な長文より短い断定。

### 誘導（CV）

1. **最初のCTAは早く。** 冒頭で結論を出したら、間を置かずボタンへ。
2. **締めは読者主語。** 読者の“道のり”に共感→「でも大丈夫」でリフレーム→**読者の具体的な問いを列挙**（「もう登録してしまった」「払う前に止めたい」）→低ハードル→「相談してよかった、と思ってもらえるように」。
3. **「一般論でなく私が直接」。** 「ネットやAIで調べても当たり障りのない答えしか返らない。だから私が直接お聞きします」。
4. **入口は広く。** その商材だけでなく、お金・副業・投資の不安全般を拾う。

### 注意

- **絵文字は persona 依存**（ここで統一しない。宮崎=😊、藤原=無し等、各 personaファイルに従う）。
- yakkeiの **FaqSchema・大赤文字1.25em・締めの見抜く力テンプレ丸貼り** は真似ない（サイトで廃止/禁止のものがある）。CVの本質＝速さ・スキャン性・具体、だけ取る。

## 冒頭の型（案件ごとに“考えて”作る・型を機械適用しない）

冒頭は「唯一の正解形」を貼るものではない。**読者の心理状態 × 案件の性質**を読んで入口を選ぶ、その判断そのものが人間味。

前のめり系（投資講座・セミナー・在宅副業・スクール）に効く共感先行の入口の例:

**before（AI寄り・ponyo）**
```
こんにちは、ヤマトです。
今回は、YouTubeで人気の【在宅副業女子】ぽにょさんが案内する在宅副業を調べました。
広告では「AI活用で5時間の労働が30分以下に」と、かなり景気のいい言葉が並んでいます。
（中略）
すると、この副業は最終的に数百万円規模の高額なコンサルへ繋がる入り口だとわかりました。
在宅副業女子ぽにょの副業は、安易な申し込みはおすすめできないと判断しました。
この記事では、私が調べてわかった広告の中身と運営会社の実態を、本音で解説していきます。
```

**after（人間味・ponyo）**
```
こんにちは、ヤマトです。

家で、すきま時間に少しでも稼げたら。

そう思って在宅の副業を探している方は、本当に多いと思います。

そんな中で【在宅副業女子】ぽにょさんの「AIで5時間の作業が30分」「未経験でも月10〜20万」という言葉を見ると、私にもできそう、とやってみたくなりますよね。

そこで今回は、ぽにょさんの在宅副業について調べてみました。

登録してしまった方も、これから申し込もうか迷っている方も、記事を読んでから冷静に判断してくださいね。
```

**何を変えたか**
- 「今回は〜検証していきます」だけの空の導入をやめ、**案件に自然に紐づく共感**を先に置いた（在宅副業＝家で稼ぎたい気持ち）。
- 登録後の案内の詳細（数百万円のコンサル等）は本文で検証する。ただし、現時点の判断と主な理由は導入で短く伝える。上の例は共感の入口を示す部分見本であり、完成稿では`writing-agent/SKILL.md`の「導入の完成条件」も満たす。
- 「本音で解説します」の**宣言を消した**（言うだけで中身がない）。

**時事フックの例（案件に紐づくものだけ）**: 投資=物価高/新NISA、物販=副業解禁、占い=先の見えない不安。**毎回同じ枕（「AIが発達した今〜」等）を全記事に貼らない**＝同型化はそれ自体が新しいAI臭さ。

## 入口のバリエーション（“共感先行”だけを正解にしない）

**最重要の注意：上の共感先行は「入口の一例」であって唯一の正解形ではない。** これを毎回貼ると、旧「今回は〜検証します」と同じ“新しい定型”になり、また同型化＝AI臭さに戻る。冒頭は下のパターンから、**読者の心理状態 × 案件の性質**で毎回選ぶ。その選択そのものが人間味。

| 入口の型 | どんな時に効く | 例（1行イメージ） |
|----|----|----|
| ①共感先行 | 前のめり系（在宅副業・投資講座・スクール・占い）。読者の願望から入る | 「家で、すきま時間に少しでも稼げたら。」 |
| ②一次情報フック | 広告や特商法に“強い数字/矛盾”が出ている案件。実物を先に見せて違和感を作る | 「広告には『月収30万円』。でも料金の記載はどこにもありません。」 |
| ③相談フック | 相談が実際に来ている案件。社会的証明＋当事者性 | 「先日LINEに『これ本当に稼げますか』と相談が届きました。」 |
| ④違和感・第一印象フック | 怪しさが直感で来る案件。キャラの主観を最初に立てる | 「正直、この広告を最初に見て思ったのは『うますぎないか？』でした。」 |
| ⑤キャラの実体験フック | 失敗談に紐づけられる案件。親近感でキャラを売る | 「私も昔、“誰でも稼げる”の一言で痛い目を見ました。」 |
| ⑥時事フック | 案件に自然に紐づく世相がある時だけ | 投資=新NISA、物販=副業解禁、占い=先の見えない不安 |

**回すルール**:
- **同じ型を連続させない。** 直近数本が①共感先行で揃っていたら、次は②〜⑤に振る。「全部①」も「全部②」も同型化。
- どれを選んでも、後半の**「そこで今回は〜調べてみました」→寄り添い→LINE**の着地は共通で使ってよい（着地は骨格、入口は毎回変える）。
- 型を混ぜてもいい（②で数字を見せてから①の共感に繋ぐ等）。表は“発想の引き出し”であって埋める枠ではない。
- 参考: fbssの2026-07-06の6本は①共感先行で統一した（旧「今回は〜検証します」からの底上げ）。**次からは①に固定せず②〜⑥を回すのが正しい運用。**

#### 導入で先に伝える範囲

現時点の判断と、その主な理由は導入で伝える。例：申込みを急がない方がよい／総額や返金条件が確認できないため。

「ネタバレを避ける」とは、判断理由を隠すことではない。証拠画像の詳細、個別の数字の検証、登録後の案内の全容などを、導入で説明し尽くさないという意味である。

「おすすめしません」だけで終わらせず、読者がその判断を理解できる理由を短く添える。

## 第三者ではなく、目の前の1人に話しかける（納品前に必ず実測する）

> 「〜です。〜ます。ばっかり。多分これ第三者に向けて書きすぎなんだと思う。
> 全くユーザーに刺さらない記事。ただの情報・ニュースサイトになってるよ。
> **自分が営業マンだとして、自分を信用してもらうために、自分のラインに登録して
> もらうために、信用づけのために記事書かないと。不特定多数じゃなくて、
> 1人のお客さん（ユーザー）に書くつもりでやって**」（管理人さん 2026-08-28）

**症状は語尾に出るが、原因は宛先。** 誰に向けて書いているかが「不特定多数」だと、
文が全部「〜しています」「〜ありません」の三人称報告になり、ニュースサイトになる。

### 実測（2026-08-28・副業データバンクの3本）

| | 直す前 | 直したあと |
|---|---|---|
| です・ます率 | 79% / 82% / **86%** | 76% / 79% / 77% |
| 読者への問いかけ | **175段落中 0回・1回・0回** | 7回 / 5回 / 6回 |

**問いかけが3本合わせて1回。** キャラファイルには「この時点でかなり不自然ですよね」型が
**声を出すための1番目のテクニック**として書いてあるのに、1度も使っていなかった。

### 納品前に数える（文章で決めない）

```bash
# です・ます率と問いかけ数。目標＝です・ます 75〜80%・問いかけ 5回以上
python3 - <<'EOF'
import re,sys
f=sys.argv[1] if len(sys.argv)>1 else "記事.mdx"
fm=0;inbal=False;body=[];tot=0;desu=0
for ln in open(f,encoding="utf-8"):
    t=ln.strip()
    if t=='---': fm+=1; continue
    if fm<2: continue
    if t.startswith('<Balloon'): inbal=True; continue
    if t.startswith('</Balloon'): inbal=False; continue
    if inbal or t.startswith(('|','!','#','>','import','※')): continue
    t=re.sub(r'<[^>]+>','',t).strip()
    if not t: continue
    body.append(t)
    for s in re.findall(r'[^。！？]*[。！？]', t):
        tot+=1
        if re.search(r'(です|ます|ません|でした)[。！？]$', s.strip()): desu+=1
q=sum(1 for t in body if re.search(r'(ですよね|ますよね|でしょうか|ませんか|よね。)', t))
print(f"です・ます {desu*100//tot}%  問いかけ {q}")
EOF
```

### 直し方（飾りを足すのではなく、宛先を変える）

| 三人称の報告 | 目の前の1人に向けた言い方 |
|---|---|
| ただ、この10個は「動画を見るだけ」でいい人には要らないものばかりです。 | ただ、動画を見るだけの人に、SEO対策も集客も画像制作も要りませんよね。 |
| 1円でも入れば、この例外からは外れます。 | さっきの教材、目標は「数百円でも十分」でしたよね。<br>数百円が入った時点で、返金の窓は閉まります。 |
| ただ、まだ3か月の会社が300万円の道具を売っているとなると、判断材料は少なくなります。 | ただ、できて3か月の会社に300万円を渡せるかというと、**私には無理です**。 |
| その発信が1件も無いのは、それ自体が情報です。 | その発信が1件も無いという事実が、いちばん分かりやすい答えです。 |
| 実在する放送局のロゴが背景に入り、字幕は〜となっています。 | 背景には実在する放送局のロゴ、字幕は〜。（**体言止め**） |

- **「読者」ではなく「あなた」に届く言い方にする。**「読者が確かめる手段がなくなります」→「あなたが確かめる手段はここで無くなります」
- **一人称の主観を出す。**「〜と考えられます」ではなく「私には無理です」「私はそう思います」
- **体言止めを混ぜて語尾を割る。** ただし `1文1段落` ゲートがあるので、体言止めは**必ず単独の段落**にする
- ⚠️ **飾りを足すのではない**（[[humanize-plainer-not-fancier]]）。文を派手にせず、**宛先だけ変える**
- ⚠️ **問いかけを機械的に等間隔で撒かない。** 読者が「え？」と思う場所にだけ置く

## 判断の姿勢（最重要）

- **0-100で考えない。言い方次第。** 「調べました」等のメタ・過程の言及を全部悪と決めて機械的に消すのは誤り。人間味・好奇心・共感を伴えばOK。禁じるのは“空っぽ・ドライ・自己弁護”な言い方だけ。

- **対面営業テスト＝主語は「相手が受け取るもの」。** 目の前の客に「ここから私が確かめた流れなんですが」とは言わない＝私の作業実況はNG。「実際に登録した結果をお伝えすると」＝相手に結果を渡すのはOK。迷ったら“対面営業ならこう言うか？”で判定する。主語が「私の作業（確かめた／解説していく／まとめていく）」になっていたら、「相手が受け取るもの（こういう流れになります／結果はこうでした）」に置き換える。

  良い例（運営会社セクションの入り・ponyo after）:
  ```
  ここまでの内容で、もう十分あやしいな…と感じている方も多いと思います。

  では、運営している会社そのものに、怪しい点はあるのでしょうか。

  どんな会社なのか、運営元の情報もしっかり調べました。
  ```
  → 読者の疑問を“共感”として起こし、好奇心を作ってから「調べました」＝人間味があるのでOK。同じ「調べました」でも、ドライに言えばNG・人間味を乗せればOK。

- **人間味＝プレーンではない。** 太字/マーカー/色を削りすぎると読みにくい＝基本（モバイル装飾密度）違反。千葉さんの記事も人間味がありつつ要所は装飾されている。声を変えずに要点へ装飾を入れる。
  - 装飾は**共感の枕には付けない**（例「家で、すきま時間に少しでも稼げたら。」は無装飾でよい）。
  - 装飾は**実質・価値・キー主張**に置く（例「私が検証して安全性を確認できた副業情報」＝LINEの価値／広告の謳い文句＝`<mark>`／結論・警告＝赤太字）。
  - 「装飾なし◯連続」warn を、枕に装飾を足して消そうとしない。中身のある所に置く。

## 一人称の主観（“危険です”で止めない）

事実の判定で終わらせず、キャラ自身の選択として言い切る。千葉さん「私だったら別の資産運用にします」「あくまで、私だったら参加しない、という感じですね！」。

**ponyo after（結論）**
```
在宅副業女子ぽにょの副業は、詐欺とまでは言い切れませんが、払うお金に見合う中身があるとは思えず、私はおすすめしません。
```
「危険と判断しました」より、「私はおすすめしません」「私だったらこの入り口はくぐらない」の方が人間で、キャラが立つ。
