# キャラ作成 — 運営者ペルソナをゼロから作る

新サイトの「運営者キャラ（記事を書く人格）」を、**対話だけでゼロから**組み立てる。
完成したら `skills-local/writing-agent/references/personas/<キャラ名>.md` に保存し、writing-agent がそのキャラとして記事を書けるようにする。

## 絶対の原則（必ず守る）

- **既存キャラ（他サイトの運営者）を一切引き合いに出さない。** 「○○みたいな感じ？」は禁止。**初めての人・他キャラを知らない人でも答えられる、自己完結した質問だけ**する。
- 例を示すときも、キャラ名ではなく**一般的な方向性**で示す（例：「ベテラン寄り / 同世代の仲間寄り」）。
- **ユーザーの答えだけ**からキャラを組み立てる。答えていない項目を勝手に断定で埋めない（提案して確認を取る）。
- **1問ずつ聞く。** 一度に大量に聞かない。答えづらい項目は選択肢の方向性を添える。
- ユーザーが「おまかせ」と言ったら、サイトのジャンルに合う自然な設定を**提案し、必ず確認を取る**。

## 埋める先

テンプレ：`skills-local/writing-agent/references/personas/_template.md`（【】が空欄）。
このテンプレの各欄を、以下の質問で順番に埋めていく。

## 進め方（順番に1問ずつ）

### 1. サイトの方向性（最初に土台を決める）
- このサイトは何を扱う？（ジャンル・テーマ）
- サイトのゴールは？（例：問い合わせ / 登録 / 資料請求 など）
- 読者はどんな人？（どんな悩み・状況の人が読む？）

### 2. キャラの基本情報
- ペンネーム（呼び名）は？
- 一人称は？（私 / 僕 / 俺 / アタシ など）
- 年齢・居住地・家族構成は？（任意。信頼感に効く範囲で。言いたくなければ空でOK）
- イメージカラーは？（サイトの主役色。未定なら後回しでOK）

### 3. キャラの核（一番大事・時間をかける）
- このキャラを一言で言うと？（読者にとってどんな存在か）
- なぜこのジャンルを発信している？（背景・きっかけを2〜3個のエピソードで）
- 読者への立ち位置は？（例：先を行く先輩 / 同じ目線の仲間 / 冷静な専門家 など。※他キャラ名は出さない）

### 4. 文体・トーン
- 語り口は？（です・ます / だ・である / カジュアル）
- 感情の出し方は？（共感多め / ツッコミ多め / 冷静 など）
- 絵文字は使う？（使うなら種類と使う場面 / 使わないならその旨）
- 専門用語はどう扱う？（噛み砕く / カッコ書きで補足 / なるべく避ける）
- 結論の言い切り方は？（はっきり断言 / やわらかく示す など）

### 5. 仕上げ
- 挨拶（記事冒頭の一言）と締め（記事末尾の一言）
- このキャラがよく使う口ぐせ・言い回し（2〜3個）

## 完成させる

1. 集めた答えで `_template.md` の【】を全部埋めた**新しいファイル**を作る。
2. 保存先：`skills-local/writing-agent/references/personas/<キャラ名を小文字ローマ字>.md`（例：`tanaka.md`）。**`_template.md` は消さずに残す。**
3. **抜け・矛盾チェック**：空欄(【】)が残っていないか／語り口とトーンがちぐはぐでないか／核と文体が一致しているかを確認し、あればユーザーに確認する。
4. 完成したら次を案内：「このキャラで記事が書けます（writing-agent）。運営者情報などの固定ページを作るなら site-identity を使ってください」。

## やらないこと
- 既存キャラの設定をコピー／参照／引き合いに出す（禁止）。
- ユーザー未回答の項目を勝手に断定で埋める（必ず提案→確認）。
