# 書き方の見本と、消すべき癖

`SKILL.md` の原則を守ったうえで、書き始める前に開く。**丸写ししない。同型化＝AI臭に戻る。**

---

## 三点の見本（丸写し用でなく、崩して使う）

**決まった型はない。** これは発想の引き出しで、埋める枠じゃない。唯一の縛りは、AI感を出さないことと、`check-line-cv.sh` のNGを踏まないこと。それさえ守れば、書き方は毎回自由に変えていい（同じ型の使い回し＝同型化＝AI臭に戻る）。〇〇＝商材、△△＝案内人。

### 冒頭

**相談が来た体**
```
こんにちは、〇〇です。
今回は、△△が案内している「〇〇」について調べました。
「登録してしまったんですが、大丈夫でしょうか」という相談が、いくつか届いていたからです。
先に、実際に登録して調べた結論をお伝えします。
〇〇は、おすすめできません。
これから始めようか迷っている方も、もう登録してしまった方も、最後まで読んでから判断してください。
```

**広告の矛盾から入る**
```
「スマホひとつで月30万円」——〇〇の広告には、そう書かれています。
ただ、肝心の「何をして稼ぐのか」は、どこにも書いていません。
気になったので、実際に自分で登録して、中身を最後まで確かめてきました。
結論から言うと、〇〇はおすすめできません。
```

**読者の迷いから入る**
```
「〇〇って、本当に大丈夫なのかな」
そう思ってこの記事にたどり着いた方が、多いと思います。
その感覚は、たぶん間違っていません。
実際に登録して調べたところ、〇〇はおすすめできない、という結論になりました。
```

### 記事内（不安の頂点＝結論直後・料金直後に置く。調査セクション中は置かず信頼を積む）

**結論の直後**
```
とはいえ「じゃあ何なら大丈夫なのか」が分からないと、結局また同じような広告に手を出してしまいます。
そこだけは、一般論では答えられません。あなたが今どこにいるかで、答えが変わるからです。
もし迷っているなら、今の状況を一言だけ送ってください。
その内容を見て、私がお答えします。
```

**料金・実態の後（立場で分ける）**
```
ここまで読んで、「もう払ってしまった」という方もいると思います。
その場合は、早めに一度、状況を聞かせてください。動くのが早いほど、できることは残っています。
まだ払う前の方は、お金を払う前に一度、聞かせてください。
私が実際に続けている副業の話も、必要なら共有します。
```

**口コミの後（短く）**
```
「この口コミ、本当かな」「自分は稼げるのかな」
そう感じたときは、抱え込まずにLINEから聞いてください。
一人で判断しなくて大丈夫です。
```

**今すぐ困っていない人へ（登録のメリットを示す・一言は"滲ませる"）**
登録だけで無反応も惜しい。でも「一言送って」と直接言うと、困っていない人には押し売り臭い。だから命令せず、軽い口実と"読者側のメリット"で滲ませる。
```
今すぐ聞きたいことがなくても、登録だけしておいてもらえたら大丈夫です。
新しい副業の情報が入ったら共有しますし、いざというときにすぐ聞ける相手がいると、それだけで楽になります。
もし気が向いたら、「どんな副業やってるんですか」くらいの一言でも構いません。
そのほうが、あなたに合いそうな話をお送りしやすいので。
```
※「一言送ってほしい」を直接言わない。口実（軽い質問）を渡し、送る理由を"あなたに合う話が届く"＝読者メリットにする。「私が返したいから」にしない。

### クロージング（記事のゴール。赤字は使わない）

**失敗談から**
```
正直に言うと、私も過去に、これと似たようなもので失敗しています。
「今度こそは」と思って進んで、時間もお金も無駄にしました。
その経験があるので、こういう広告を見ると、どこで人がつまずくのかが分かります。
もし今、どう判断すればいいか分からないなら、今の状況をそのまま聞かせてください。
同じ遠回りをしてきたぶん、無駄な回り道は減らせると思います。
一言で構いません。必ずお返事します。
```

**読者の感覚を肯定する**
```
ここまで読んだということは、どこかで「何かおかしい」と感じていたんだと思います。
その感覚は、正しいです。
副業で稼ぎたい気持ちが、悪いわけではありません。ただ、わざわざ危ない道を選ぶ必要はないだけです。
どの道を選べばいいか迷っているなら、今の状況をそのまま聞かせてください。
一緒に考えます。一言で構いません。必ずお返事します。
```

**立場で分けて締める**
```
もし〇〇にもう登録してしまっているなら、早めに一度、連絡をください。
今どうなっているかを教えてもらえれば、次にできることを一緒に考えます。
まだ始めていないなら、お金を払う前に一度、聞かせてください。
どちらの場合も、抱え込まないでください。
一言送ってもらえれば、私がお返事します。
```

## AIが外す典型（＝直すべき自分の癖）

- **情報で答えようとする。** 「〇〇について教えます」＝AIと同じ土俵。→ "あなたの状況を人間が見る"に立てる。
- **寄り添うだけで手ぶら。** 「不安なら相談してください」で止まる＝押す理由がない。→ 逃げ道・次の一歩を具体的に出す。
- **読者を採点する。** 「〜して正解」「偉い」＝気取ったラベル貼り。→ 次の行動だけ言う。
- **気の利いた言い回しに盛る。** プレーンでいい所を凝る＝新しいAI臭。
- **副業自体をディスる。** 読者のやる気を折る＝自分も選ばれない。
- **審判者・自己弁護・催促煽り。** `check-line-cv.sh` が弾く（「私は〜と思います」「無理な勧誘はしません」「追加しただけだと見落とすかも」）。

## 書いた瞬間に消す7つのAI癖（実記事で全部抜いた・機械ゲートを通っても残る）

CVが出ない検証記事は、中身でなく"書き方"で落ちている。以下は `check-*` を通っても残る癖。**書いた直後に自分で全文を走査して消す（1つずつ指摘されるのは失格）。** 判断基準はひとつ——**その文は絵に描けるか／行動に移せるか。描けない・動けない文は飾り＝スロップ。**

1. **空ラベル締め** … 具体を書いた後に抽象名詞で締める（「〜なパターン／場所／防ぎ方／典型です」）。→ 事実か"次の行動"に置換。
2. **思わせぶり** … 「間に合います」「できることが残っています」＝何に？何が？ → 具体に（「カード会社に連絡すれば支払いを止められる」）。
3. **裏づけない最上級** … 「詐欺がいちばんよく使う手口」「絶対に」「数多く」。データが無いなら書かない。→ その記事の事実で言える範囲に。
4. **行き先・主語のないCTA** … 「送ってください」「連絡すれば」だけで、どこに・誰にが無い。→ **行き先＋ハードル下げを1文に**（例「下のボタンから、私のLINEに今の状況を送ってください」「下のボタンから気軽に聞いてください」）。
5. **未確認情報** … 「名前を変えて何度でも出てくる」等、裏の取れない断定。→ 削るか「同じ手口が○○でも見られた」の比較に留める。
6. **ですます単調** … 語尾が全部です／ます。で退屈。→ 体言止め・言い切り・短い断定を混ぜる。
7. **自分主語のもったいぶり** … 「いちばん念入りに調べました」「ここからが本題」「いちばん気になるところ」＝読者でなく筆者が主語。→ **読者の疑問に置換**（「○○にお金を預けていいのか、運営会社も調べた」）。

**立場で分けるCTA（取りこぼし防止）**：「まだ払ってない人」だけに向けると、いちばんホットな"もう払った人（火消し）"を捨てる。両方に別々の次の一手を——未入金＝ここで止めれば被害ゼロ／既払い＝カード払いなら支払いを止められる場合があるので、やり方はLINEで。

## CTAの見返りと、行き先の出し方（連呼するな）

- **CTAは「行き先」だけでなく「送る理由＝見返り」を必ず出す。** 「状況を送ってください」だけは手ぶらで、読者は"なんで送るの？"で終わる。「実際に登録して確かめたので、あなたの場合はどうすべきかを具体的に言える」等、読者の得を一言添える。ただし「ネットは一般論しか返さないから私が答える」の定型丸出しは避け、その案件の事実で言う。
- **見返りは記事の判定と矛盾させない。** 危険・要注意の記事で「続けて大丈夫か教えます」はNG（続けていい余地をにおわせ、記事と矛盾）。「いま止めるべきか／もう払ったお金を取り戻せるか」に振る。
- **行き先フレーズを連呼しない。** 「下のボタンから」を全CTAに貼ると、逆にスパム臭で胡散臭くなる。1〜2回に絞り、他は「私に」「私のLINEに」「気軽に聞いて」で散らす（ボタンは直下にあるので毎回明示しなくていい）。

## 読者の言葉に翻訳する（知っている前提で書かない）

読者は投資の素人で、LPの用語も"なぜ危ないか"も知らない。**LPの煽り文句・専門語を引用しただけで放置しない。必ず平語に訳す。** 判断基準は「読者がその一文で絵を描けるか」。

- **専門語は訳す。** ×「スピードとレバレッジで収益を増やす」→ ○「レバレッジとは手持ち以上のお金を賭ける仕組み。当たれば大きいが、外れれば手持ちが一気に減る」。×「記事のような体裁の広告」→ ○「記事をそっくり真似た偽の広告」。
- **煽り数字は"なぜ異常か"を言う。** ×「3ヶ月で2倍と景気のいい言葉」→ ○「3ヶ月で2倍は、プロでもまず出せない数字」。
- **抽象語で逃げない。** ×「良い数字を大きく見せて可能性に触れない／そのまま信じない」→ ○「儲かった人の数字だけ載せ、損した人の話は一つも出さない」。
- **読者に宿題を出さない。** ×「あなたが運営元を確かめるほうが大事」＝素人に丸投げで、"筆者が代わりに調べる"という価値提案とも矛盾。→ 事実を言い切るか、自分が調べた結果を見せる。

## 不安一本道 → 救済の構成（記事全体の型）

CVを最大化する全体設計。**読者の不安を具体的に積み上げ、逃げ場を1つずつ塞ぎ、最後にLINE（相談）を"救済"として差し出す。** 分析口調で淡々と説明するのでなく、読者の感情を動かす。〇〇＝商材。

**⚠️ 使いどころ＝ジャンルを選ぶ（最重要）。** この型が効くのは、MLM・ネットワークビジネス・サブスク／継続課金など、読者が"すでに毎月お金を払っている・やめられない"**継続的な痛みを抱えている案件**。痛みリストが「今の自分だ」と刺さる。逆に**投資・情報商材・一回課金の詐欺は、読者が「これ本物？買う価値ある？」と判断したくて事実を求めているモード**なので、痛みリストで感情を煽ると的外れになる。そこは **answer-first（結論と事実を冒頭で先に出す）** が合う。ジャンルを見て使い分ける。以下は前者（継続トラップ系）の型。

**冒頭の型（この順で、ただし短く・スキャンできる形で）:**

1. **迷いを言い当てる。** 「〇〇って本当に稼げるの？」「友達に誘われたけど…」＝読者の頭の中の言葉で始める。
2. **痛みを具体リストで自分ごと化。** AlertBoxで箇条書き（毎月の出費が生活を圧迫／人間関係がぎくしゃく／使わない在庫の山 等）。※タイトルは「〜になっていませんか？」だと参加済み限定になる。未参加にも効く「〇〇を始めると、こうなりがち」にする。
3. **相談者の声で共感。** 「私のLINEにも"〇〇で△△になった"という声が」＝一人じゃない。※筆者の自分語り（過去の失敗談）でなく相談者の声で寄せる。
4. **恐怖を増幅し、逃げ場を塞ぐ。** 「このまま続けても金は出ていく一方」「一度始めるとやめるのも簡単じゃない」。※やめられない"理由"は冒頭で明かさずオープンループにして本文で払う（＝読み進めさせる。冒頭で全部説明するとネタバレで離脱）。
5. **「でも、大丈夫です」で反転。** 独立行で転換点を強調。ここから救済に切り替わる。
6. **記事が価値を出すと約束。** 「この記事で費用・稼げるか・断り方まで見せます」。※LINEだけに絞ると記事を読みに来た人が離脱する。まず読ませて、LINEは受け皿にする。
7. **能動CTA。** 「気になれば送って」の受け身はCVが弱い。「一人で決める前に一度、状況を送って」＝決断の後押し＋低ハードル。**ただし登録煽り（今登録しないと損／一言ないと見落とすかも）は禁止＝ブーメラン＆check-line-cv.shが弾く。煽るのは"状況（読者の損）"、LINEは"逃げ道"。**

**本文〜まとめ:** 各セクションの締めを次の不安へ繋ぎ（出し惜しみ繋ぎでタメるのでなく中身を名指しつつ）、いちばん逃げにくい事実を恐怖のピークに置き、まとめで「一人で抱えるほど損。LINEで一緒に」＝救済に着地。

**恐怖は捏造しない。** 合法企業・グレー案件で煽る"恐怖"は、一次ソースのある実在する損だけに限定（毎月の赤字・在庫・解約の縛り等）。詐欺と断定できない相手を詐欺扱いしない（名誉毀損回避）。
