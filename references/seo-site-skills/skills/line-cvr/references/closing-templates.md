# クロージングの型（型①〜⑩）

`SKILL.md` の判定表で型番号を決めてから開く。**必ず実測欄を先に読む。**
実測が ❌ の型は使わない。未検証の型を使うときは、適用日をメモして日次で前後比較する。

**⚠️ 実測を追記するときのルール**：デプロイ日のCTは動作確認クリックが混ざるので数えない。
同じ記事を短期間に何度も書き換えると判定不能になる。1回直したら数日空ける。

## クロージングの型（管理人さんの実物アンカー＋ジャンル別バリエーション）

**この節のアンカー＝管理人さんが別サイトで実際に使っていたクロージング**（下の①がほぼ原文）。CVが出ていた実物なので、**迷ったらこの温度に寄せる**。上の「三点の見本」がパーツの引き出しで、ここは"締めの完成形"の見本集。

### 骨格（5ビート・順番を守る）

| # | ビート | やること |
|---|--------|---------|
| 1 | **期待値を先に下げる** | 「すぐに億が稼げる情報は持っていない」＝誇大な結果を自分から否定する。ここで誠実さが立つ |
| 2 | **でも着実な道はある、と言い切る** | 1で下げた分を回収する。案件ジャンルに合わせて「人を誘わない」等に振る（※「お金をかけない」への振りは不可・下記ルール参照） |
| 3 | **読者の状態を2つ並べる** | 「本気で始めたい」／「誰かに相談したい」＝前向きな人と迷っている人の両方を拾う |
| 4 | **一人称の裏打ちで差し出す** | 「私が実際に運用して確信できたものなら共有できます」。一般名詞のギブより強い |
| 5 | **低ハードル＋必ず返信** | 「一言で構いません」「必ず返信します」。ゴールは登録でなく返信 |

**この型が効く理由**＝1で「盛らない」を先に見せているので、4のギブが売り込みに聞こえない。**2〜4だけを書くと、ただの勧誘になる。1を省略しない。**

※この5ビートは①〜⑧（儲けたい読者から入る型）の骨格。**⑨ AI時代型だけは入り口が違うのでビート1を入れない**（詳細は⑨の節）。

### 共通ルール

- **1記事につき1つ。** 9つ全部を並べない。同じジャンルの記事が続くときは、丸写しせず言い回しを毎回崩す（同型化＝AI臭）。
- **「必ず返信します」は締めで1回だけ。** 連呼するとテンプレになる。
- **数字は"否定形"でだけ使う。** ビート1で「すぐに億が稼げる情報は持っていない」と否定するのはOK（＝期待値を下げる本体）。逆にビート2〜4で「月7桁」「不労所得」のような数字を約束として出さない（期待値を上げ返して1が台無しになる。藤原専用語でもある）。
- **「教えます」断定にしない。** 「お伝えします」「共有します」で着地（各サイト `CLAUDE.md` の絶対ルールと衝突しない）。
- **「お金をかけずに稼げる」を刷り込まない。** ビート2で「お金をかけずに始められるやり方」のような"元手ゼロ"を約束すると、読者に「お金は出さなくていい」が刷り込まれ、この先に案内する投資・高額商材への課金が入りにくくなる（管理人さん指摘）。代わりに「私が実際に取り組んで、安全性を確認できたやり方」「少額から試せるもの」「まずは私のやり方を真似るだけでいいもの」に振る。
- **クロージングに赤字は使わない**（既存ルール）。太字・マーカー・青字で。
- 1文1段落・モバイル3行以内は当然守る。

### ⑨ AI時代型（入り口が①〜⑧と違う。5ビートに乗せない）

**実測**: 未検証（型として適用前後を比較した記録がない）

**①〜⑧は「儲けたい読者」の期待値を下げてから回収する型。⑨だけは「騙されたくない読者」から入る。** そのため**ビート1（期待値を先に下げる）を入れない。** 「儲かる話は持っていません」を差し込むと、直前まで積んだ"見分けられない不安"と接続せず、そこで文章が死ぬ（実際に一度そう書いて没にした）。

不安を積んだまま「私は見分ける手段を持っている」で受けるのがこの型の骨格。**理屈が一本で通っていることが本体**なので、途中の一文を差し替えるときも因果を切らないこと。

```mdx
AIが誰でも使えるようになって、怪しいサービスは一気に増えました。

昔のような、作りの粗い詐欺サイトはもう出てきません。見た目だけなら本物と区別がつかないからです。

だから今は、安全かどうかを自分で見分けるのが本当に難しい。

かといって、AIに聞いても検索しても、その副業が安全かどうかまでは返ってきません。返ってくるのは一般論だけです。

私は、気になった副業に実際に登録して、中で何が起きるかを自分の目で確かめています。

広告や紹介ページを見ただけでは分かりませんが、中に入れば分かることがあります。

副業を始めたい人も、いま見ているものが不安な人も、下のボタンから気軽にLINEしてください。

私が知っていることは、全部お伝えします。
```

**この型の要点:**

- **AIには絶対にできないことで受ける。** 「AIも検索も答えない」と前段で言い切った以上、差し出す側は「実際に登録して中で何が起きるかを確かめている」でなければ回収にならない。「経験や知識から最適なアドバイスができます」ではAIでも言えるので前段が無駄になる
- **間口を絞らない。** 「気になっている副業があるなら名前を送ってください」のように条件を付けると、まだ何も決まっていない人と、もう払ってしまった人を落とす。「始めたい人も／不安な人も」で2状態を並べたまま受ける
- **「気軽にLINEしてください」が低ハードルを兼ねる。** 後ろに「一言で構いません」「必ず返信します」を付け足すと、AI時代の理屈で作った温度が営業テンプレに落ちる。⑨では付けない
- **「被害が急増しています」のような裏づけのない断定を混ぜない。** 前段の説得力は因果で出しているので、数字で盛る必要がない
- 前半4行はどの記事でも同じ理屈になるため、**そのまま貼ると全記事が同型化する。** 2行目（詐欺サイトの見分けがつかない理由）を、その記事で実際に見た事実に差し替えて崩す

### ⑩ 情報過多×目利き型（ジャンルを名指ししない・受け皿が無い案件でも使える／管理人さん指示 2026-08-22）

**実測**: ❌ **落ちた。使わない。** 2026-08-22に nhk-no の `hayashi-noriyuki-toushibu` と `nba-blockchain` へ適用（commit 0e2c342）。
適用前5日 合算 492PV/15CT（3.05%）→ 適用後4日 433PV/5CT（**1.15%**）。期待13件に対し観測5件で p<0.01。
2026-08-25に管理人さんの判断で差し戻し（commit 2a3dc76）。
※ただし適用前のNBA側は6CTのうち5CTがデプロイ日に集中しており、動作確認クリックの疑いがある。**デプロイ日のCTは実数として数えない。**

**⑨と同じくビート1（期待値を先に下げる）を使わない。** 入り口は「儲けたい読者」でも「騙されたくない読者」でもなく、
**「探しても選べない読者」**。だから **その記事のジャンルに受け皿（配信中の広告）が無くても成立する**のが最大の利点。

**この型を使う理由（実測）**：nhk-no の28日でジャンル別にCT率を割ると、当選金・支援金・スマホ副業・FXは10%超、
**株式投資とMLMは1%台**だった。低いジャンルは記事の出来ではなく**渡せるものが無い**のが原因で、
そこへ「私が運用しているものを共有します」と書くと、登録した人に渡すものが無い＝空振りになる。
[[cta-dont-anchor-a-price-ceiling]]と同じで、**書けない約束をCTAに置かない**。

```
（1）いまは副業も投資も、調べれば情報だけはいくらでも出てきます。

（2）<mark>その中から本当に安全なものを自分で見分けるのは、正直むずかしいです</mark>。

（3）★その記事だけの事実を1つ★

（4）私はずっとネットビジネスで稼いできたので、どれが危なくて何なら続くのかは見れば分かります。

（5）立場を2〜3つ並べる（迷っている／もう払った／これから始めたいだけ）

（6）どの状況でも、そのままLINEに送ってください。

（7）<strong>私が自分で手を動かして続けているものも、あわせて共有できます</strong>。
```

**守ること:**
- **（3）は必ずその記事の一次情報に差し替える。** ここを固定すると全記事が同型化する（⑨と同じ罠）。
  実例＝林則行「4年外れ続けている予想でも、『今度こそ当たる』と言われれば信じてしまいます」／
  NBA「運営自身が『必ず得られるものではありません』と書いていても、勧誘の場でその話は出てきません」
- **（1)(2)(4) も記事ごとに言い回しを崩す。** 2本目以降は語彙を替える
  （「調べれば情報だけはいくらでも出てきます」↔「検索すると、出てくる数だけはいくらでもあります」など）
- **ギブは「私が自分で手を動かして続けているもの」まで。** ジャンル名（株・FX・物販）を書かない。
  書いた瞬間に受け皿の約束になる。**返金・解約・断り方の代行も書かない**（上の「手続きの代行を約束しない」）
- **煽るのは「情報の海で自力で選ぶ危うさ」だけ。** 「今登録しないと」型は `check-line-cv.sh` が弾くしブーメラン
- 「教えます」断定は使わない。「共有できます」「お伝えできます」で着地
