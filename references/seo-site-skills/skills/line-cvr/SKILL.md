# LINE CVR スキル（LINE登録を最大化する書き方）

このサイト群のゴールは「LINEに一言もらうこと（CV）」。記事もSEOも全部その導線。
writing-agent（新規）・rewrite-agent（リライト）の両方が読む共通教材。

## 手順（この順で必ず）

1. **読者の状態を実クエリで判定する** → 下の判定表で型番号を決める
2. **`references/closing-templates.md` のその型を開く** → 実測欄を見る（❌の型は使わない）
3. **口調を合わせる**（下の「まず口調」）。中身が正しくてもAI口調だと押されない
4. **書いたら `scripts/check-line-cv.sh` に通す**。審判者・自己弁護・催促煽りは0許容

---

## 1. どの型を使うかを、実クエリで決める

**推測で決めない。Search Consoleでその記事に実際に来ているクエリを引いてから決める。**
記事の商材ジャンルではなく、**着地している読者がどの状態か**で型が変わる。

| 実クエリに多いもの | 読者の状態 | 型 |
|---|---|---|
| 返金 / 騙された / 詐欺 / 振り込んだ | もう払ってしまった | ⑤ |
| 潰れる / 解約 / 退会 / やめたい / 会費 | 毎月払い続けている | ④ |
| 勧誘 / 断り方 / ねずみ講 / アムウェイ / MLM | 人を誘う形が苦しい | ③ |
| 評判 / 口コミ / 料金 / 費用 + スクール・講座名 | まだ払っていない | ② |
| 投資 / 運用 / 予想 / トレード | 投資・資産運用 | ① |
| 当選 / 給付金 / 支援金 / お金配り | 切迫度が高い | ⑧ |
| 商材名の単独指名だけ・滞在が短い | 今すぐ困っていない | ⑦ |
| 叩ける材料が出てこなかった | 正規・合法と判明 | ⑥ |
| どれにも寄らない・見分けたいが主 | AI時代型 | ⑨ |

**⑩（情報過多×目利き型）は現時点で使わない。** 実測で落ちている（`references/closing-templates.md` の実測欄）。

**1記事につき型は1つ。** 複数の状態が混ざっている記事は、実クエリのクリック数が最も多い状態に合わせる。

## 2. 勝ち記事を見本にしない（いちばん破られているルール）

nhk-no の実測で記事内CTAが5〜8%出ているのは kifutown / smarita / cocotalk など**ギフトカード・当選金の被害層**で、
その誘導文は「支払いを止めることが最優先」「番号を送ってしまった方も、まず私に聞いてください」＝**手続きの代行寄り**。
**CT率だけ見て他記事へ横展開すると、テイカーを増やす型を全サイトへ配ることになる。**
見るべき指標はCTではなく、その先の案件登録。CTランキングは「どの記事が読まれているか」までの参考に留める。

---

**なぜここに書いてあるか**：2026-09-02、このスキルを読まずに `/tsukutsuku-abiru/` を直したセッションが、
CT率13.8%の `/fxverge/`（＝当選金・被害層タイプ）を物差しにして「1.8%は記事側の欠陥」と診断し、
候補記事をCT率で並べ替えて優先順位を決めた。**このルールはスキル内にあったが、153行目に埋まっていて読まれなかった。**

**CT率でやってよいこと**＝どの記事が読まれているかの把握まで。
**CT率でやってはいけないこと**＝見本の選定、優先順位づけ、成否の判定。

## まず口調（ここが土台。中身より先）

同じことを言っても、AI口調で言った瞬間に嘘くさくなって押されない。だから中身より先に、まず喋り方をここに合わせる。

- **一文を短く。改行でどんどん区切る。** 長い説明文にしない。
- **話し言葉で、読者に隣で喋りかける。** 「〜ですね」「〜んですよ」は入れすぎない程度に。
- **断定は柔らかく置く。** 「〜と言えます」「〜かもしれません」「〜という印象です」。
- **盛らない・飾らない・気の利いたことを言おうとしない。** プレーンが正解。
- **読者を採点しない。** ❌「まだ始めてないなら止まって正解です」「〜できたのは偉い」＝行動にラベルを貼って点数をつける気取り。→ ただ次にどうすればいいかを言うだけ。※読者の"感覚"を肯定するのは可（「その感覚は、たぶん間違っていません」）。ただし決め台詞にしない。
  - **線引き：読者の"主体的な一歩"を認めるのはOK**（「ここまで調べたのは、自分で確かめようとしたからですよね」）。cheapな行動ラベル（止まって正解）はダメだが、"自分で動いた"ことを認めるのは背中を押す。ただし芝居がかった言い方（「辿り着いたのは偶然じゃありません」等）にはしない。
- **重すぎず軽すぎず。** お金がかかっている話。軽いノリ（「痛い目にあった」「溶かして」「当たりますよ」）は誠実さを削るので避ける。落ち着いた、正直なトーンで。

口調がズレていたら、中身が正しくても押されない。書いたら声に出して読んで、"人がこう言うか？"を確かめる。

**勝ち記事（CVが出ている記事）の文面も、そのままコピーしない。** 実際に効いている記事でも、言い回しには若干のAI臭が残っている（「潜入して」のような芝居がかった語＝胡散臭い）。参考にするのは"誘導の狙い・ニュアンス"だけで、言い回しは必ず自分でde-AIし直す（この口調の章に従う）。

## 中身の軸：AIに返せないものを差し出す

**一番大事な考え方。** 「〇〇は安全？」という疑問の"答え"なら、AIやAI検索が返す。それで済むなら、読者はそもそも記事に来ない。

**わざわざ記事まで来て、さらにLINEまで動く人が求めているのは、AIが構造的に返せないもの。**

- 一般論でなく、"自分の"この状況を見てもらうこと
- 情報でなく、同じ失敗をした人間の判断
- ちゃんと返事が来る、個別の対応

だからCTAは「情報をあげます」で立てない（それはAIと同じ土俵＝負ける）。**「あなたの状況を、私が直接見て、一緒に考える」**で立てる。

軸になる一言：
> 「ネットやAIで調べても、当たり障りのない一般論しか返ってきません。でも本当に知りたいのは、"あなたの場合はどうなのか"のはずです。だから私が直接お答えします」

「安全な副業情報を共有します」のような具体的なギブを出してもいい。ただしそれは**正直な検証で信頼を作った"後"**だから効く（＝誠実な人からの提案）。順序が逆（いきなり教えます）だと押し売りになる。**信頼 → ギブ。**

**ギブは「私が"実際に運用している／取り組んでいる"もの」と一人称で裏打ちする**と信用される。「安全な副業情報」という一般名詞より、"自分が現にやっている"方が強い。

## 🚫 CTAで絞り込まない（何度も指摘されている・最重要）

**受け手を条件で絞る書き方をしない。** 相談に答えること自体は問題ない。問題は「どういう人か」を細かく限定すること。

> 「副業に関する相談とか、これ稼げる？系はいんだよ。問題はめちゃくちゃ詳しく絞り込んでること。
> 絞り込むなって何回も言ってるやん」（管理人さん 2026-08-22）

**❌ 絞り込み（受け手を限定している）**

- 「**いつ入金したのか**を教えてもらえれば、今いくら引かれている可能性があるか一緒に計算します」
- 「**提示された金額で回収できるのか**を一緒に見られます」
- 「**説明された内容**を聞かせてもらえれば、その先どこで止まるかまで具体的に言えます」
- 「**どんな言い方で誘われたか**を聞かせてもらえれば、同じ団体かどうか分かります」
- 「**この画面まで進んで、入力していいのか迷って手が止まっている方**もいると思います」

**⭕ 広い（誰でも送れる）**

- 「**名前だけ送ってもらえれば、調べたことがあるものはその場でお答えします**」← 管理人さん承認
- 「副業のことなら何でも聞いてください／私が知っていることは、そのままお答えします」
- 「人を誘わずに続けられる副業なら、私がいまやっているものをお伝えできます」

**判定のしかた**：その一文を読んで「自分は当てはまらない」と思う読者が出るなら絞り込み。
立場の並記（誘われている／もう入っている／これから稼ぎたい）は**並べる**ので絞り込みではない。

## 🚫 対応者ができないことを約束しない

**LINEに対応するのは記事の書き手ではない。** 作業・計算・手続きを引き受ける約束は、登録直後に辻褄が合わなくなる。

> 「一緒に計算とかLINE対応側が困る！やり方わかってる人みたいな感じになるのはダメかも」（管理人さん）

❌「一緒に計算します」「解約手続きを一緒にします」「返金の方法をお伝えします」「カード払いを止める手順もLINEで」
⭕「知っていることはそのままお答えします」「私が続けているものを共有できます」

**線引き**：**答えるのはOK。作業を引き受けるのはNG。**

---

## 🚫 手続きの代行を約束しない（ゴールは案件登録・管理人さん指示 2026-08-22）

**LINEの最終目的は、登録者に案件へ登録してもらうこと。相談窓口や何でも屋ではない。**

> 「相談って言っても何でも屋じゃないし、最終的にはラインの案件に登録させることが目的だから
> それはわかってないとダメだよ。私がなんでもします！返金方法も解約手続きもします！じゃ
> ただのテイカーだよ」（管理人さん）

**書いてはいけないギブ**（押させても案件に進まない人＝テイカーを集める）

- 「カード払いなら支払いを止められる場合があるので、その連絡先と手順もLINEでお伝えします」
- 「返金の方法をお伝えします」「解約手続きを一緒にやります」「断り方の文面をお渡しします」
- 手続き・書面・窓口を**こちらが代行する**という約束すべて

**書いてよいギブ**

- 「私が自分で手を動かして続けているもの」＝**次に何で稼ぐか**
- 「止めるかどうかを決めたあとに、次に何で稼ぐかまで含めてお伝えできます」
  （火消しの立場は受けるが、渡すものは稼ぎ方に寄せる）

**立場の並記（もう払った／まだ）は今までどおり残す。** 狭めると逆にCVが落ちる
（[[cta-narrowed-to-already-paid-kills-cv]]）。変えるのは**立場ではなく、約束する中身**。

## 記事内CTAで死ぬ書き方（実測）

記事内CTAのクリック率は同じボタン・同じ画像・同じ計測でも **7.9%〜0.26% と23倍差**が出る。
0.26%だった共済会の8箇所は全部これだった。

- ❌「断り方も、会費を止める順番も、下のボタンから**聞けます**」
- ❌「報酬の仕組みは、いま案内されている内容に当てはめて**一緒に見られます**」

**情報の申し出で終わっていて、押す理由がない。** かつ手続き寄りでテイカーを集める。
直し方は、立場を1行で受けてから**ギブ（私が続けているもの）**へ着地させる。
**クロージングの文面を記事の途中に持ってきてよい**（短縮版でよい）。

### 比喩でギブを言わない（2026-08-28・管理人さん「本当に意味わからん　何のつもりでこれを書いてるの？」）

「私が続けているもの」を渡す型は、**言い換えた瞬間に何も伝わらなくなる。** 読者はその一文で絵を描けず、押す理由も生まれない。

- ❌ 返ってくる側の作り方なら、私がいま手を動かしているものをお伝えできます。
- ❌ そのあと何で埋めるのかまで含めて、私のほうからお伝えできます。
- ❌ 誰も誘わずに自分の手だけで積み上げるやり方なら、私が続けているものをお伝えできます。

**直し方は、凝った言い回しを足すことではなく、素の言葉に戻すこと。** 立場を並べた1行で受けて、
「LINEで状況を教えてくれれば、こう答えられる」まで平語で書く。

```
誘われて参加を考えていた方でも、すでに登録してしまった方でも、状況を整理することが大事です。

LINEで状況を教えてくれれば、今後どう動いていけばいいか、具体的なアドバイスもできるので、気軽にメッセージを送ってくださいね。
```

## 4つの動き（どの案件でも同じ）

1. **逃げ道を作る。** 否定で終わらせない。「これは危険。でも安全な道は別にある」。行き場を失った読者に、LINEが次の一歩として立つ。
2. **やりたい気持ちを殺さない。** 副業/投資そのものは否定しない。「稼げないんじゃなくて、どの情報を信じるかの問題」。読者は稼ぎたくて来ている。その気持ちを肯定した上で、正しい入口として自分を置く。**仕組み・手法そのものも叩かない（中立に切り分ける）**：「IB報酬／シグナル配信という仕組み自体は悪くない、問題は悪用する業者」のように。ヒステリックに全否定せず、フェアに切り分けるほど信用が増してCVに効く。
3. **立場で分ける。** もう登録した人＝火消し（「早いほどできることが残っている」）／まだの人＝止める＋選択肢の共有。それぞれに具体的な次の一歩。
4. **権威は肩書きでなく経験から。** 「私も過去に似たもので失敗した → だからどこでつまずくか分かる」。失敗談が権威にも親近感にもなる。
5. **問題がない人も歓迎する。** 誘導を「不安がある人・もう登録した人」だけに絞らない。今すぐ聞きたいことがなくても、**登録しておくメリット**を示す＝新しい副業情報を共有する／何かあったときすぐ聞ける相手ができて楽／備えになる。「今は特にないけど一応」で登録できる入口を、重い誘導とは別に用意する。

**ゴールは登録でなく返信。** 「一言だけ送ってください」「必ずお返事します」。友だち追加させて放置されたら意味がない。送らせて初めて成立する。ただし④の"問題がない人"向けは、まず登録のハードルを下げるのが先でよい。
