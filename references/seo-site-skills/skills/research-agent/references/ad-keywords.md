# 広告キーワード生成パターン

副業検証記事のGoogle広告出稿用キーワードを生成するためのルール。

---

## キーワードパターン

商材名・会社名・人物名をそれぞれ `{名称}` として、以下のパターンで組み合わせる。

### 1. ネガティブ系

ユーザーが不安を感じて検索するキーワード。最も検索ボリュームが大きい傾向。

| パターン | 例 |
|---------|-----|
| `{名称} 詐欺` | マネーキャッチ 詐欺 |
| `{名称} 怪しい` | マネーキャッチ 怪しい |
| `{名称} 危険` | マネーキャッチ 危険 |
| `{名称} 嘘` | マネーキャッチ 嘘 |
| `{名称} 悪質` | マネーキャッチ 悪質 |
| `{名称} やばい` | マネーキャッチ やばい |
| `{名称} 被害` | マネーキャッチ 被害 |
| `{名称} トラブル` | マネーキャッチ トラブル |

### 2. 調査・検証系

| `{名称} レビュー` | マネーキャッチ レビュー |
| `{名称} 本当` | マネーキャッチ 本当 |
| `{名称} 実態` | マネーキャッチ 実態 |
| `{名称} 検証` | マネーキャッチ 検証 |
| `{名称} 稼げる` | マネーキャッチ 稼げる |
| `{名称} 稼げない` | マネーキャッチ 稼げない |

### 3. 運営元調査系

## 表記ゆれの対応

同じ商材でも複数の表記が使われることがある。以下のパターンをチェックする。

| 種類 | 例 |
|------|-----|
| カタカナ / ひらがな | マネーキャッチ / まねーきゃっち |
| カタカナ / 英語 | マネーキャッチ / Money Catch |
| 漢字 / ひらがな | 副業革命 / ふくぎょうかくめい |
| 略称 | マネーキャッチ / マネキャ |
| スペースの有無 | マネー キャッチ / マネーキャッチ |

表記ゆれが確認できたものは、主要な表記ゆれパターンでもキーワード候補を生成する。

---

## 除外ルール

以下に該当するキーワードは候補から **除外** する。

| 除外条件 | 理由 |
|---------|------|
| 「副業」「投資」「ネットビジネス」単体 | 範囲が広すぎて費用対効果が低い |
| 「稼ぐ方法」「副業 おすすめ」等の一般ワード | 商材名を含まないため関連性が低い |
| 競合他社の商材名単体 | 他社の商標に抵触する可能性 |
| 明らかに無関係な複合キーワード | 検索意図がずれている |

---

## ボリューム推定基準

WebSearchの結果から、おおまかなボリュームを推定する。

| ボリューム | 基準 |
|-----------|------|
| **大** | 検索結果に複数のレビューサイト・掲示板の書き込みが表示される |
| **中** | 検索結果にいくつかの関連ページが表示される |
| **小** | 検索結果がほとんどない、または無関係な結果が多い |
